Deliverable Format What it's for
Fertilizer Zone Map Shapefile + controller packages (with offline MBTiles basemap) Maps relative-vigor zones and encodes the selected direct, inverse, or operator-supplied rate strategy. An optional MBTiles orthomosaic provides visual context where the target application supports manual import.

Stress Hotspot Map GeoJSON + KML + CSV Pinpoints lowest-performing field zones for targeted ground scouting.
Prescription Report PDF + PNG map Review report covering fertilizer rates and zones, spot-spray targets, field metrics, limitations, and controller-loading checks.
Technical GIS & Audit Data GeoTIFF + CSV + JSON Raw spectral health layers (NDVI/NDRE/MSAVI2), per-zone statistics, and audit log.
