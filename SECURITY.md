# Security Policy

## Supported versions

Security fixes are applied to the latest release only. Upgrade to the newest published plugin ZIP before reporting an issue.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue before a fix is available. Email `nyashashekede990@gmail.com` with:

- the affected OrthoSWIFT and WebODM versions;
- reproduction steps or a minimal proof of concept;
- expected impact;
- any proposed mitigation;
- whether the report may be acknowledged publicly after remediation.

Do not include sensitive customer imagery or credentials unless an encrypted transfer method has been agreed first. Uploaded geospatial files and ZIP archives are treated as untrusted input.
